Connect this phone to GitHub

Once per phone. Make a token that can only touch this one repo.

  1. On github.com go to Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
  2. Repository access: Only select repositories, pick silly-spaces.
  3. Repository permissions: Contents, Read and write. Pull requests, Read and write.
  4. Generate, copy it, paste it below. It stays in this browser only.
